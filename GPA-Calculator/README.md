# GPA Calculator

## Description

A beginner Python program that calculates a student's GPA based on course grades and credit hours.

## Features

- Enter course grades
- Enter credit hours
- Convert letter grades into grade points
- Calculate GPA
- Display the student's final GPA

## Python Skills Practiced

- Variables
- User input
- Dictionaries
- Lists
- Functions
- Conditional statements
- Mathematical calculations

## Purpose

This project was created to practice Python programming fundamentals by building a practical tool for calculating GPA.

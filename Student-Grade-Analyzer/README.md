# Student Grade Analyzer

## Description
A beginner Python program that allows users to enter multiple grades and analyzes the results.

The program calculates the average grade, determines the average letter grade, and identifies the highest and lowest grades.

## Features
- Enter multiple grades
- Calculate the average grade
- Determine the average letter grade
- Find the highest grade
- Find the lowest grade
- Handle cases where no grades are entered

## Python Skills Practiced
- Variables
- User input
- Lists
- While loops
- If/elif/else statements
- Functions
- Mathematical calculations
- Built-in Python functions such as sum(), max(), and min()

## Purpose
This project was created to practice applying Python fundamentals to a simple data-analysis problem.
